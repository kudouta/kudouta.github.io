この記事で何を扱うかを、最初の1段落で簡潔に書きます。読者が「自分に関係あるか」を判断できるよう、前提・対象読者・結論をここで示しておくと親切です。

## はじめに

背景や問題設定を書くセクションです。なぜこの話題を取り上げるのか、どんな課題を解決するのかを説明します。

**メモ:** 補足や前提条件は通知ボックスで目立たせると読みやすくなります。
{: .notice--info}

## 環境

検証に使った環境を明記しておくと、再現性が上がり読者の信頼を得られます。

| 項目 | バージョン |
|------|-----------|
| OS | Ubuntu 24.04 |
| Ruby | 3.3.x |
| Jekyll | 4.x |

## 手順

### 1. セットアップ

まず必要なものをインストールします。コードブロックは言語名を指定するとシンタックスハイライトが効きます。

```bash
bundle install
bundle exec jekyll serve
```

### 2. 設定

設定ファイルを編集します。

```yaml
# _config.yml
title: "My Tech Blog"
locale: "ja-JP"
```

### 3. 動作確認

期待される出力を示します。インラインで `コマンド名` のようにコードを書くこともできます。

**警告:** 破壊的な操作や注意が必要な箇所は danger ボックスで強調します。
{: .notice--danger}

## ハマりやすいポイント

実際に詰まった箇所と解決策を残しておくと、同じ問題に遭遇した読者の助けになります。

1. エラーの内容
2. 原因
3. 解決方法

> 引用や公式ドキュメントからの抜粋はこの形式で示します。
> 出典を明記しておきましょう。

## まとめ

この記事で扱った内容を箇条書きで振り返ります。

- ポイント1
- ポイント2
- ポイント3

関連資料へのリンクやボタンを置く場合は以下のように書けます。
